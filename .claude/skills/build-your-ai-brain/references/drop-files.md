# Sorting files and pasted content

Use this in Step 1, and any time the owner says "sort my files".

## For each file in `Drop files here/` (or each thing pasted in chat)

1. Read it. PDFs, Word docs, slides, spreadsheets, text, screenshots and images are all fine. If you can't open one, say which and ask them to paste the text or save it as PDF.
2. Work out what it is: price list, proposal, brochure, website copy, SOP or checklist, onboarding doc, brand guide, logo, team list, testimonials, emails or messages they wrote, financial summary, something else.
3. Pull the useful facts into the right brain file:

| What it is | Goes to |
|---|---|
| Price list, packages, proposal | `2 Sales/Offers and Prices.md` |
| Testimonials, reviews, case studies | `2 Sales/Customers.md` (exact words) and `1 You/Stories.md` (client wins) |
| Emails, captions, messages they wrote | `3 Marketing/Brand Voice.md` (examples) and `1 You/Writing Rules.md` (patterns) |
| Brand guide, logo, colours, fonts | `3 Marketing/Brand Look.md` |
| SOP, checklist, onboarding doc | `4 Operations/Processes.md` |
| Team list, org chart, roles | `5 Team/Team.md` |
| Reports, dashboards, financial summary | `6 Finance/Key Numbers.md` |
| About page, bio, pitch deck | `1 You/Profile.md`, `1 You/Stories.md` |
| AI brain quiz answers (`AI Brain quiz answers.md`, from the quiz on our website) | Each section goes to the brain file it names (Profile, Customers, Offers and Prices, Team, Processes, Tools, Key Numbers, Goals). The owner gave these answers, so skip those questions and confirm them in one line instead. Keep the file in `Sources/`. |

4. Move the original file into `Sources/` (keep its name, add the date in front if there's a clash). Don't delete anything. **Exception:** if the file has any of the private details below, don't move it. Save a cleaned copy in `Sources/` with those lines removed, leave the original where it is, and ask the owner to delete the original or move it out of the brain folder now. Add it to "Still to confirm" until they do.
5. Note at the bottom of each brain file you added to: `From: [[Sources/<file name>]]`.

## Before you file anything

- Leave out passwords, bank and card details, and tax file numbers. If a file has them, tell the owner you skipped that part (see the exception in point 4).
- Clients' private details stay out of the brain: phone numbers, addresses, and names next to health, legal or money details. Use "a client in Darwin" instead.
- Contradictions (a 2023 price list vs the website) → write both with `[CHECK]` and ask.
- Brain files sorted here start as `status: draft`. The interview confirms them; don't tick them off in `_Setup Progress.md` until then.

## When done

Tell them in 2 or 3 lines what you found and where it went, e.g. "Your price list went into Offers and Prices. The two SOPs went into Processes. I skipped the bank details in the onboarding doc."
