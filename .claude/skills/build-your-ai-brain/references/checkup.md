# Monthly brain check-up

Use when they say "brain check-up", "update my brain", or "something changed". About 10 minutes.

## Steps

1. Read `CLAUDE.md`, `_Setup Progress.md` and the `updated:` date on every brain file. If setup isn't finished, offer to continue it instead.
2. Sort anything sitting in `Drop files here/` (see `drop-files.md`).
3. Ask these, one at a time. Skip any that clearly don't apply.
   - Any new offers, price changes, or things you've stopped selling?
   - Anyone joined or left the team? Any role changes?
   - New tools, or tools you've dropped?
   - Any new client wins or stories worth keeping?
   - Has anything changed with your goals or what you're focused on?
   - Anything the AI got wrong this month, or wrote in a way you didn't like?
4. Update the right files. Change the `updated:` date on each file you touch. When a new fact replaces an old one that came from a file in `Sources/`, remove the old fact from the brain file and change its `From:` line to `From: [[Sources/<file>]] (out of date since YYYY-MM-DD)`. If a new file was added, add it to the list in `Start Here.md`. Add a `Writing Rules` "Never" line for anything the AI got wrong in their writing.
5. Flag stale files: anything not updated in 6 months gets one question ("Your Key Numbers are from March. Still about right?").
6. If the changes affect the roadmap (new tools, new goals, a big hand-off done), offer to refresh `Roadmap.md`.
7. Save a short note to `Check-ups/YYYY-MM-DD.md`:

```
# Check-up YYYY-MM-DD

## Changed
- <file>: <what changed>

## Still to confirm
- <anything marked [CHECK]>
```

8. Close in two lines: what changed, and "See you next month."

## Rules

Same as the build: only facts they give you, no passwords or private details, draft don't send.
